# lan-topology-simulator

NodeItem - класс отрисовки узлов сети в симуляторе топологии LAN. Он отвечает за визуальное представление каждого узла, включая его положение, цвет и состояние.

Мак адрес:
	Состоит из 6 байт: XX : XX : XX : XX : XX : XX
Один байт — это 8 бит:[бит 7] [бит 6] [бит 5] [бит 4] [бит 3] [бит 2] [бит 1] [бит 0]
Первые 2 байта особенный: 1й-всегда четный, 2й - значения 2 ,6,10...+4 означают что мак прописан ручками 

	Бит 0 (самый младший) — это I/G (Individual / Group):
Если он равен 0 ? это Unicast (адрес принадлежит конкретному компьютеру/порту).
Если он равен 1 ? это Multicast / Broadcast (групповой адрес).
	Бит 1 — это U/L (Universal / Local):
Если он равен 0 ? Universal (заводской адрес, прошитый производителем Intel, Cisco, Realtek на фабрике).
Если он равен 1 ? Locally Administered (локально администрируемый / программный адрес).
